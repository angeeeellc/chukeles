============== PROYECTO CHUKELES ==============

Este directorio contiene el código fuente del proyecto Chukeles, listo para ser ejecutado. Se ha omitido cualquier archivo generado automáticamente o dependencias pesadas (node_modules, target, etc.) para que el peso del archivo sea manejable.

--- ESTRUCTURA DEL PROYECTO ---

1. /backend:
   Contiene el código fuente de la API del servidor (Backend), desarrollado en Java con el framework Spring Boot.
   - Para ejecutarlo localmente: Necesitarás Java (JDK 17+) y Maven. Puedes usar `./mvnw spring-boot:run`.

2. /frontend:
   Contiene el código fuente de la interfaz de usuario, desarrollado con React, TypeScript y Vite.
   - Para ejecutarlo localmente: Necesitarás Node.js. Ejecuta `npm install` para descargar las dependencias, y luego `npm run dev` para iniciar el servidor de desarrollo.

3. /docker y docker-compose.yml:
   Archivos de configuración para desplegar el proyecto usando contenedores Docker.
   - Para levantar todo el proyecto (Base de datos, Backend y Frontend), puedes usar el comando: `docker-compose up --build` en la raíz del proyecto.

4. /data:
   Contiene el script SQL de inicialización de la base de datos (`seed.sql`). Se ejecuta automáticamente al levantar el proyecto con Docker.

5. Archivos de entorno (.env y .env.example):
   Configuración de variables de entorno (como credenciales de base de datos o claves de API).

-------------------------------------------------
Para la evaluación, puedes usar Docker para probar la aplicación de forma rápida, o levantar los servicios de backend y frontend de forma individual mediante Maven y NPM respectivamente.
